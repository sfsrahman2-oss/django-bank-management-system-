# Bank Management System

A Django-based Bank Management System for managing user accounts, deposits, withdrawals, and transaction history.

## Features

- User Registration
- User Login and Logout
- Bank Account Creation
- Deposit Money
- Withdraw Money
- Current Balance Management
- Transaction History
- Transaction Search
- Date Filtering
- Dashboard Statistics
- Bootstrap UI
- CSV Transaction Export
- Dark Mode

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap 5
- JavaScript
